# Browser Support

InkLayer Core separates browser build compatibility from runtime interaction
support. The packed Vite/Webpack matrix is documented independently in
`docs/consumer-build-matrix.md`; this document records browsers that have run the
real Viewer and Annotation application.

## Current declaration

| Engine | Playwright build | Status | Evidence |
|---|---|---|---|
| Chromium | Chromium 1234 | Verified | 14 automated Vanilla scenarios plus manual Viewer/Worker, Range, recovery, scale, annotation, keyboard-focus, long-document, and raster-print checks pass without unexpected console warnings or errors. |
| Firefox | Firefox 1538 | Verified | The same 14 automated Vanilla scenarios pass, including structured recovery, Range, mixed-page geometry, long-document lifecycle stress, cross-page selection, keyboard movement/focus, menu handoff, and reduced motion. |
| WebKit | WebKit 2336 | Verified | The same 14 automated Vanilla scenarios pass, including structured recovery, Range, mixed-page geometry, long-document lifecycle stress, cross-page selection, keyboard movement/focus, menu handoff, and reduced motion. |

The declared engine matrix is Chromium, Firefox, and WebKit. These Playwright
builds are the reproducible release baseline; they do not imply validation of
every historical browser or every vendor-specific Safari release.

## Runtime surface

Every browser project shares the same 14-scenario suite and covers:

- zero-configuration PDF.js Worker loading and rendered pages;
- generated bytes, encrypted-password input, local files, and HTTP Range with
  progress, cancellation, retry, headers, and repeated reload;
- thumbnails, outline, search highlighting, same/cross-page text selection, and
  selection-first markup;
- built-in and custom annotation creation, image-backed signature/stamp,
  selection, transformation, FreeText, comments, tags, and native import;
- single and continuous layout scale presets, Ctrl/Meta-wheel zoom, and
  opposing two-touch pinch input;
- direct-document keyboard selection/movement/deletion, visible semantic focus,
  FreeText focus restoration, TextLayer menu handoff, and reduced-motion page
  navigation;
- raster print preparation, PDF/Excel export, multi-instance isolation,
  remount cleanup, and the mobile layout breakpoint;
- deterministic 96-page search, virtual-page mounting, thumbnail/object-URL
  churn, repeated zoom, cancellation, and document replacement;
- structured URL, Range, incorrect-password, raster-render, and explicit-load
  cancellation recovery with successful instance-owned retries;
- browser console warnings, errors, and uncaught page failures.

## Commands

The default local release check uses the installed Chromium baseline:

```sh
npm run test:browser
```

Install the other engine binaries once, then run the declaration matrix:

```sh
npx playwright install firefox webkit
npm run test:browser:matrix
```

CI installs all three engines. It runs Chromium through `npm run check`, then
runs the Firefox and WebKit projects as a second browser gate.
